# proyecto-ig

En este proyecto realizado para la materia Informática General 2024, planifiqué, diseñé y desarrollé un sitio web sobre un artista musical utilizando HTML, CSS y JavaScript.
El sitio cumple con requisitos impuestos por la cátedra como: ser respomsive, utilizar un framework CSS y librerías JavaScript, desarrollar la interactividad para el funcionamiento de una galería de fotos y para validar el formulario de contacto, como mínimo.
